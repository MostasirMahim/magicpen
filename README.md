# 🪄 Magic Pen 3D Telegram Store Bot (@magicpen3d_bot)

একটি পরিপূর্ণ টেলিগ্রাম ই-কমার্স প্রোডাক্ট অর্ডারিং ও কাস্টমার ম্যানেজমেন্ট বট।

---

## 🚀 প্রধান ফিচারসমূহ (Features)

1. **ইন্টারেক্টিভ কাস্টমার মেনু:**
   - প্রোডাক্ট ফিচার ও ডেসক্রিপশন
   - ইনস্ট্যান্ট অর্ডার বাটন
   - কাস্টমার সাপোর্ট যোগাযোগ
   - অর্ডার ট্র্যাকিং (`/myorder`)

2. **সম্পূর্ণ অর্ডার ফ্লো (FSM Order System):**
   - পরিমাণ নির্বাচন (১ পিস, ২ পিস, ৩ পিস বা কাস্টম)
   - গ্রাহকের নাম
   - সচল ১১ ডিজিটের মোবাইল নম্বর ভ্যালিডেশন (বাংলা ও ইংরেজি উভয় ডিজিট সাপোর্ট)
   - ডেলিভারি জোন নির্বাচন (ঢাকার ভেতরে ৳৮০ / ঢাকার বাইরে ৳১৪০)
   - বিস্তারিত হোম ডেলিভারি ঠিকানা
   - পেমেন্ট মেথড (Cash on Delivery অথবা bKash / Nagad Send Money সহ TrxID ইনপুট)
   - অর্ডার সামারি যাচাই ও চূড়ান্ত কনফার্মেশন

3. **অ্যাডমিন অ্যালার্ট ও কন্ট্রোল সিস্টেম:**
   - নতুন অর্ডার সাবমিট হলেই অ্যাডমিনের পার্সোনাল টেলিগ্রামে সরাসরি ইনস্ট্যান্ট নোটিফিকেশন মেসেজ চলে যাবে।
   - অ্যাডমিন মেসেজের নিচে থাকা ইনলাইন বাটন (`✅ কনফার্ম করুন`, `❌ বাতিল করুন`) দিয়ে এক ক্লিকেই অর্ডার কনফার্ম বা ক্যানসেল করতে পারবে।
   - অর্ডার কনফার্ম বা ক্যানসেল করার সাথে সাথে স্বয়ংক্রিয়ভাবে কাস্টমারের কাছে স্ট্যাটাস আপডেট নোটিফিকেশন পৌঁছে যাবে।
   - `/admin` কমান্ডের মাধ্যমে অ্যাডমিন ড্যাশবোর্ড থেকে মোট অর্ডার, পেন্ডিং, কনফার্মড অর্ডার এবং মোট সেলস দেখা যাবে।

```
├── test_bot.py           # লোকাল ডাটাবেজ ও লজিক ভেরিফিকেশন টেস্ট
├── requirements.txt      # প্রয়োজনীয় পাইথন লাইব্রেরি
├── DEPLOYMENT.md         # লিনাক্স VPS সার্ভারে ২৪/৭ রান করার গাইড
└── handlers/
    ├── start.py          # /start, /help, /product, /myorder হ্যান্ডলার
    ├── order.py          # গ্রাহকের অর্ডার ফ্লো (FSM)
    └── admin.py          # অ্যাডমিন ড্যাশবোর্ড ও অ্যাকশন হ্যান্ডলার
```

## 💻 কীভাবে নিজের কম্পিউটারে চালাবেন (Local Run)

### ধাপ ১: .env ফাইলে আপনার টোকেন দিন
`.env` ফাইলটি নোটপ্যাডে ওপেন করে আপনার তথ্যগুলো বসান:
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
ADMIN_ID=123456789
```

> **টোকেন ও আইডি পাওয়ার উপায়:**
> 1. **BOT_TOKEN:** Telegram-এ [@BotFather](https://t.me/BotFather) এ গিয়ে বটের টোকেন কপি করুন।
> 2. **ADMIN_ID:** Telegram-এ [@userinfobot](https://t.me/userinfobot) এ `/start` চাপলে আপনার `Id:` (যেমন: `123456789`) দেখাবে। সেটি `ADMIN_ID`-তে বসান।

### ধাপ ২: বট চালু করুন
টার্মিনালে কমান্ড দিন:
```bash
python main.py
```
এখন টেলিগ্রামে আপনার [@magicpen3d_bot](https://t.me/magicpen3d_bot)-এ গিয়ে `/start` চাপুন!
